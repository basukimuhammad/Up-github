ZIP to GitHub

Upload ZIP → GitHub

Ekstrak ZIP di browser dan kirim ke repository GitHub. Jika ZIP hanya berisi satu folder utama, folder tersebut akan otomatis dihapus dan file langsung ditaruh di halaman utama repo.

Gunakan token baru milikmu sendiri dengan izin Contents: Read and write pada repository tujuan. Token hanya berada di memori halaman dan dikirim langsung ke GitHub API.
