Upload ZIP → GitHub

Pilih ZIP project, masukkan repository tujuan, lalu semua file di dalam ZIP akan diekstrak di browser dan dikirim sebagai satu commit ke GitHub.

Gunakan token milikmu sendiri dengan izin Contents: Read and write untuk repository tujuan. Token hanya disimpan sementara di memori halaman.

Pilih atau jatuhkan file ZIP di sini ZIP maksimal 25 MB • maksimal 300 file
